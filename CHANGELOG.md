# Changelog

All notable changes to BestatML are documented here.

## 0.1.0 — Initial Release

- Added `BestatClassifier` and `BestatRegressor`.
- Added leakage-safe automated preprocessing.
- Added heterogeneous sklearn model registry and optional boosting integrations.
- Added cross-validation and genuine out-of-fold prediction generation.
- Added stacking, weighted blending, voting, and ensemble fallbacks.
- Added configurable hyperparameter search budgets.
- Added feature-importance and training-summary utilities.
- Added versioned `joblib` persistence.
- Added estimator, preprocessing, ensemble, persistence, and adversarial leakage tests.
- Added production-oriented validation and BestatML-specific exception handling.
